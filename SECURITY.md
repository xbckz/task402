# Security policy

Task402 handles uploaded documents, bearer capabilities, and signed payment authorizations. Please do not disclose a suspected vulnerability in a public issue or discussion.

Use GitHub's private vulnerability reporting for [`xbckz/task402`](https://github.com/xbckz/task402/security/advisories/new) when available. Include a concise reproduction, affected endpoint or file, impact, and a safe remediation suggestion. Do not include private keys, payment payloads, operator passwords, document capabilities, or private source documents in a report.

If private reporting is unavailable, contact the repository owner through GitHub before publishing details. We will acknowledge actionable reports and coordinate disclosure after a fix is available.
