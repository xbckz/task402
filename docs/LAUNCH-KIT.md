# Task402 launch kit

This is the factual copy and verification checklist for publishing Task402 to agent directories and communities. It is designed to convert discovery into a first successful paid call without promising catalog placement or traffic that has not been verified.

## Positioning

**Task402 gives AI agents bounded, citation-ready evidence from PDFs and public webpages, plus safe OpenAPI analysis and read-only Base data. Pay per operation with x402 USDC.**

## Short directory copy

> Pay-per-call evidence for AI agents. Index a native-text PDF once for $0.01, then search, cite, compare, and extract bounded evidence with included tools. Also fetch public-page evidence, inspect OpenAPI contracts, and read Base data with x402 USDC.

## Long directory copy

> Task402 is a Streamable HTTP MCP and REST service for agents that need reliable evidence without loading an entire document into model context. One $0.01 PDF indexing payment unlocks short-lived, capability-gated tools for inspection, page maps, search, batch search, context preparation, labeled fields, reading, citation verification, revision comparison, validation, and bounded page rendering. Public web evidence costs $0.005 per page; OpenAPI analysis and Base read-only calls cost $0.001–$0.002 per operation. Every paid call exposes its exact x402 v2 terms, bounded schema, idempotency behavior, and recovery contract.

## Channel-specific notes

### Official MCP Registry

Publish the checked-in `server.json` as `xyz.task402/x402-docs`. Verify that the live record shows the current release and the remote `streamable-http` URL. Registry publication proves directory visibility; it does not prove a paid call or Bazaar catalog entry.

### Glama and Smithery

Submit the remote connector URL and link the first paid call directly. Ask the reviewer to run the unsigned discovery step first; it is free and returns the exact payment terms before any wallet approval.

### x402 Bazaar

Verify the facilitator discovery response after a real approved payment. A 402 response containing Bazaar metadata proves that the service advertises a catalog entry, but it does not prove that the facilitator has indexed the resource. Keep the resource URL, tool name, transport, price, payee, and timestamp of the verified response.

## Conversion checklist

1. A visitor can reach `/docs#first-paid-call` from the homepage in one click.
2. The unsigned challenge is explained as free and safe to inspect.
3. The signed retry uses the same arguments and idempotency key.
4. The signer checks network, asset, recipient, amount, resource, and timeout.
5. The result and settlement receipt are bounded and easy to pass to the next agent step.
6. Stats distinguish discovery, challenges, settled calls, and repeat paid calls.

Do not buy synthetic traffic, publish an unverified directory claim, or place wallet keys in a browser snippet, prompt, repository, or shell command line.
